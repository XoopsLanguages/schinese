帮助：模板

说明

XOOPS 允许在站点的实际呈现（“皮肤” 或用户界面）以及在后面运行的代码。第一个是由基于图形主题的复杂机制处理的。主题的基本形式可能包括基本的 HTML 定义网站视觉界面的模板，以及补充该视觉界面所需的样式表和图像。主题可以在管理界面中切换，因此更改 XOOPS 站点的整体外观只需更改 选择器并单击“接受”。 XOOPS 还为站点管理员提供了让用户在一些可用主题中进行选择的能力。

一般来说， 主题 是网站的高级视觉框架：主题定义了网站的总体布局等；另一方面，它通常不定义块内内容的具体分布。这是由一个处理 不同的实体称为 模板集。模板集 是 HTML 模板的集合，定义了构成 XOOPS 网站的所有块中内容的呈现。如果我们想要一个更清晰的比喻，我们可以说主题就像 模板集就像是房子的建筑师，而模板集就像是室内装饰师。第一个设定了围墙并定义了总体分布，但第二个负责“敷料”那些墙。

如果活动主题是一个简单的主题，仅包含主题文件、CSS 文件和一些图像，则 XOOPS 使用默认模板集来定义块的表示。然而，一些复杂的主题足够复杂，可以包含自己的模板集。在这种情况下，该网站 管理员必须使用管理界面来设置主题和模板集。

主题怎么样 魔法 完成了吗？也就是说，HTML 模板如何包含动态内容？这不是通过镜子和烟雾来完成的，而是通过一个名为“ 聪明 实现了以前所谓的功能 变量插值。用简单的方式表达，我们可以说XOOPS系统使用PHP文件来保存模块的逻辑（访问数据库，分配变量，权限管理......），插入Smarty变量的HTML文件来管理模块的逻辑。 实际的视觉界面，以及 Smarty 引擎，用于在 HTML 中的特定位置插入值和字符串，从而构建最终用户看到的页面。总而言之，这对您意味着什么可以轻松概括：凭借其主题系统，XOOPS 可以让网站设计者构建更多内容 有趣且视觉上令人惊叹的网站，无需太关心幕后发生的事情。

克隆和下载模板集

如果您想创建自定义模板集，您可以通过选择“复制默认集（或任何其他）”克隆’链接（系统将提示您为新集命名）。与默认的不同，其他模板集可以自由编辑。 You can also save a copy of a 通过选择“将模板设置到磁盘”下载' 链接，或使用 ' 删除它删除’链接。有时您可能还会看到一个额外的‘生成’链接到尚未创建模板的新模块。

编辑模板

您可以通过浏览目录树视图查看可用模板的完整列表。当您选择模板时，XOOPS 将在编辑器中打开它，您可以在其中编辑它。

编辑模板时，如果当前主题的 theme/your theme/templates 目录下有较新的文件，则必须启用自动更新模块模板 .tpl 文件的首选项（系统模块 -> 首选项 -> 常规设置 -> 更新模块模板 .tpl 文件 从主题/你的主题/模板目录？ ->‘是的’）。一旦网站公开，就应该关闭此功能。

如果您不小心弄乱了模板，请不要忘记您可以检索“好' 从默认模板集中复制。如果您使用非标准模板，那么在开始修改模板之前将副本保存到磁盘可能是个好主意。
