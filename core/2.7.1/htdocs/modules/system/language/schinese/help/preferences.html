帮助：首选项

说明

首选项面板是您配置站点范围首选项的地方。花时间完成这些设置是值得的，因为某些设置可能会对站点的性能、安全性和易用性产生重大影响。

常规设置

这些是最重要且最常访问的首选项。您将为您的网站设置网站名称和口号。您还可以选择默认主题和管理 GUI。如果您需要在您的网站上工作，您可以为所有用户关闭它。您还可以设置模块范围的缓存 次。

元标签和页脚

元标记提供有关您的信息的信息 - 它们描述您网站的性质。它们的主要用途是帮助搜索引擎及其机器人正确索引您的网站，即帮助合适的人找到它。您提供的信息包含在每个网站的标题中 页。它应该代表整个网站的内容 - 每个页面上的元信息都是相同的，目前无法针对不同的模块或页面进行自定义。

请注意，主要搜索引擎使用不同的策略来索引网站。他们可能会对元标签赋予不同的权重，甚至完全忽略它们。仔细使用元信息可能会帮助您的网站获得更好的搜索引擎排名，并且对于寻求 有关主要引荐来源网址索引策略的信息（请参阅您的网站日志文件）。这可能会帮助您优化元信息或网站设计和内容的其他方面，以提高排名。

尽量准确、诚实地提供元信息。不要尝试‘操纵’搜索引擎以获得更好的排名 - 他们可能会识别这种行为，并且您的网站可能会被降级或从其索引中列入黑名单。

文字审查选项

XOOPS 可以自动审查您网站的访问者可能发布的不良词语，并将其替换为您选择的通用替代术语。审查功能确实会消耗一些系统资源，并且可能会稍微减慢您的网站速度。默认情况下它是禁用的。

要在您的网站上实施审查，请选择“启用’单选按钮。您需要在‘中输入不需要的单词列表待审查的话' 框，用管道字符分隔它们。该函数不区分大小写。在‘中输入合适的替换术语替换 坏话与’盒子。默认为#OOPS#。

搜索选项

搜索工具是在门户网站中查找信息的最重要工具之一。 XOOPS 搜索按模块对结果进行分类 - 根据您安装的模块，记录被标识为新闻项、下载、链接或其他类型。

默认情况下启用对站点上所有资源的全局搜索。如果禁用全局搜索，此功能将不再可用，并且搜索块将变得不起作用。 搜索的默认最小关键字长度为五个字符。任何较短的术语都将被忽略。这对于控制搜索的精度很有用，尽管对于“站点地图”之类的术语用处不大。短关键字往往更常见，因此它们往往会返回更大的结果 记录数量，其中许多可能是不相关的。较长的关键字往往会检索较少的记录，但精度较高。

搜索在计算方面相对昂贵，因此排除短期术语将减少服务器上的负载。但是，请记住，有时能够搜索短期术语很有用。

电子邮件设置

控制面板的这一部分用于配置系统的电子邮件。建议您将电子邮件传送方法保留为默认设置“PHP（邮件）”。您不需要填写 Sendmail 或 SMTP 字段，除非您使用替代电子邮件传送选项。

身份验证选项

只需将其保留在 Xoops 数据库中，您就可以忽略其中的所有其他选项。

LDAP 或 Microsoft Active Directory 服务器已添加用于身份验证，作为普通 Xoops 用户的替代方案。原因是，在许多公司中，您已经在 ADS 或 LDAP 中拥有用户数据库，他们可以使用该数据库登录 XOOPS，而无需注册另一个帐户。

系统模块设置

在这里您可以激活/停用每个系统部分，以及指定系统范围的默认值，例如每页显示的头像或图像的数量。您还可以为块、注释和所有模块选择默认编辑器。
