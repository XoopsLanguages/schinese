帮助：横幅

说明

横幅是显示在页面顶部的广告。它们可能是图像或 Flash 影片，例如疯狂旋转的 XOOPS 横幅是默认安装的一部分。 XOOPS 有一个内置系统，用于管理横幅和为广告客户创建帐户，该系统 在系统模块 -> 横幅中找到。您可以在 XOOPS 站点上拥有多个横幅 - 每次加载新页面时，显示区域都会轮流浏览每个活动横幅。

每次向访问者展示横幅时，这都算作一次“印象”，这是横幅的常见交易货币。客户通常为一定数量的展示次数付费，即让他们的广告展示一定次数。

请注意：如果您从事根据展示次数销售横幅的业务，那么您应该做一件重要的事情：转到系统模块 -> 首选项 -> 常规设置，然后填写“您的 IP 地址”字段（如果有）。这将阻止您访问 网站不被包含在展示次数中。如果不这样做，可能会被认为有些不诚实（但请注意，许多管理员没有永久 IP，例如使用拨号调制解调器的管理员）。
