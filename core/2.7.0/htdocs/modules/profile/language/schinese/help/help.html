描述

配置文件模块用于管理自定义用户配置文件字段。

安装/卸载

无需采取特殊措施，请遵循标准安装过程 - 将 /profile 文件夹解压到 ../modules 目录中。通过管理 -> 系统模块 -> 模块安装模块。

有关安装模块的详细说明可在 XOOPS操作手册

操作说明

要设置此模块，您需要：

  • Configure your preferences for the module (see ‘Preferences’) and optionally the Profile block if you intend to use it (see ‘Blocks’).
  • 编辑现有类别或添加新类别。
  • 编辑现有字段或添加新字段。您可以在此处指定哪些字段在哪个类别中可见，以及它们在用户注册期间是否可见。
  • 定义注册步骤的顺序。
  • 最后，您可以为各个字段设置权限 - 哪些字段可编辑，哪些字段可搜索。

反垃圾邮件措施

要最大限度地减少垃圾邮件注册，请执行以下操作：

  • 转到管理中的保护器模块，转到首选项，然后在底部的此选项中： “阻止论坛垃圾邮件” 检查在 www.stopforumspam.com 数据库上注册的垃圾邮件发送者的 POST 数据。
    设置为“禁止IP（无限制）”

  • 在 /class/captcha/config.php 中，确保模式设置为“文本”：

    返回 $config = 数组(
    'disabled' => false, // 禁用验证码
    'mode' => 'text', // 默认模式，可以选择 'text', 'image', 'recaptcha'(需要 api key)
    'name' => 'xoopscaptcha', // 验证码名称
    'skipmember' => true, // 跳过会员验证码检查
    'maxattempts' => 10, // 每个会话的最大尝试次数
    );

  • 在“配置文件”模块中，转到“管理”，然后在“基本”步骤中位于：
    /modules/profile/admin/step.php?id=1
    将“停止后保存”设置为“否”


  • 在配置文件首选项中，将“第二个注册步骤后使用验证码”选项设置为“是”（这是默认值）
