如何使用 XOOPS？

XOOPS 是一个用 PHP 编写的 MySQL 数据库的 Web 应用程序平台。它的面向对象使其成为开发小型或大型社区网站、公司内部和企业门户、博客等的理想工具。为了有效地使用 XOOPS，您需要 安装提供您正在寻找的功能的模块。里面有很多不同的模块 模块存储库，从日历、照片库，通过新闻、公告板，到 天气更新。

如何使用帮助中心？

帮助中心旨在为您提供与管理各个功能相关的基本信息。每当您想了解有关您所在的特定页面的更多信息时，只需单击右上角的帮助图标

如何在 XOOPS 中创建内容？

你需要一个模块。这可以是新闻模块或内容模块。
