帮助：头像

说明

头像是可以在网站周围的各种内容设置中使用的小图形或图片。它们通常用在用户名旁边以添加一些“视觉识别”。 Typical applications are the forum.

头像管理器允许站点管理员添加、编辑或删除系统头像以及自定义头像。

系统头像

系统头像是由站点管理员在头像管理器部分上传的图像。

自定义头像

自定义头像是用户直接上传的图像。为了使用户能够上传头像，必须在站点首选项的用户信息设置中配置正确的选项。

编辑和删除头像

站点管理员可以编辑所有系统头像的名称和显示顺序，也可以删除其中任何一个。请注意，如果站点管理员删除用户正在使用的头像，该用户将丢失其头像。
