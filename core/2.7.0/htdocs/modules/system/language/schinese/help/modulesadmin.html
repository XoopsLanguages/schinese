帮助：模块

说明

模块是一种软件构造，它利用 XOOPS 提供的基础设施，让网站管理员向网站用户提供使用 Web 界面生成的动态或静态内容，而这些界面通常不太容易使用。

XOOPS 的部分功能在于模块的管理方式。网站管理员可以轻松安装、卸载、激活或停用任何特定模块（出于显而易见的原因，系统模块除外）。还可以重命名模块，并确定它们的顺序 在站点菜单中向最终用户显示（如果您希望它们完全显示），因为您还可以提供隐藏功能，定义对临时用户不可见的活动模块。例如，您可以通过禁用来将模块定义为在菜单中不可见 检查菜单栏中的图标。因此，对于新闻模块，您可以向选定的用户组发送私人消息，并告诉他们访问该目录，在 URL 字段中输入地址，例如 http://www.yoursite.com/modules/news.

要更改模块的顺序（这将反映在菜单中），您只需将模块拖放到所需的位置即可。

模块安装需要一些规划，包括要显示的模块以及页面上的布局。最好查看其他 XOOPS 站点并查看哪些模块用于显示各种类型的内容。通过打开任何 XOOPS 站点并将鼠标悬停在 左侧面板和右侧面板上的菜单链接。同时查看浏览器状态栏中显示的 URL。您应该看到如下地址： http://the_site.com/modules/news/.... 所有模块都存储在 /modules/ 目录中，因此以下扇区 地址（在此示例中为“新闻”）显示将显示该菜单链接内容的模块。

如果您打开链接页面，它将显示一个示例，说明如何使用该模块及其显示的内容类型。查看类似的其他网站也将使您对布局和设计功能有一些深入的了解。
