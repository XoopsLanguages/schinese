帮助：群组

说明

XOOPS 包含一个会员注册系统 - 您可以选择要求人们注册您的网站才能访问某些区域或功能。例如，大多数网站都要求人们先加入，然后才能在论坛中贡献新闻或发布消息。
XOOPS 网站的访问和管理权限是通过基于“用户组”的灵活权限系统设置的。默认组包括匿名用户、注册会员和网站管理员，但当然您可以根据需要定义任意数量的组来管理您的站点。每组可 被授予一组独特的访问权限，用于管理：

- 可以看到哪些块
- 可以访问哪些模块
- 可以管理哪些模块
- 系统管理的哪些方面可以修改

您可以更改这些默认组的名称，但不能删除它们。还可以设置和定义其他用户组，如下所述。

自定义组也可以通过组管理页面创建。
